# حکم آنلاین (نسخه وب چندنفره)

بازی حکم برای ۲ تا ۴ نفر با مرورگر (موبایل و کامپیوتر).

## اجرا روی کامپیوتر خودت (تست محلی)

```bash
cd hokm_web
pip install -r requirements.txt
python server.py
```

بعد در مرورگر باز کن:

- روی همان سیستم: http://127.0.0.1:5000  
- روی گوشی در همان Wi‑Fi: http://IP-کامپیوتر:5000  
  (IP را با `ipconfig` در ویندوز ببین)

**توجه:** در این حالت کامپیوتر باید روشن باشد.

---

## اجرا بدون روشن بودن کامپیوتر (روی اینترنت)

باید پروژه را روی یک هاست رایگان بگذاری، مثلاً **Render**:

1. کد را در GitHub آپلود کن (پوشه `hokm_web`)
2. در [render.com](https://render.com) یک **Web Service** بساز
3. Build: `pip install -r requirements.txt`
4. Start: `gunicorn --worker-class eventlet -w 1 server:app`
5. لینک عمومی می‌گیری، مثلاً:  
   `https://hokm-xxxx.onrender.com`

از آن به بعد با گوشی همان لینک را باز می‌کنی؛ کامپیوتر خانگی لازم نیست.

---

## نحوه بازی

1. یک نفر **ساخت اتاق** می‌کند و کد ۵ حرفی را می‌فرستد  
2. بقیه با **ورود به اتاق** و همان کد وصل می‌شوند  
3. میزبان **شروع بازی** را می‌زند  
4. حاکم مشخص می‌شود، حالت و حکم انتخاب می‌شود، بازی شروع می‌شود  

---

## فایل‌ها

- `server.py` — سرور و منطق بازی  
- `templates/index.html` — صفحه اصلی  
- `static/game.js` — کلاینت  
- `static/style.css` — ظاهر موبایل‌فرندلی  
- `requirements.txt` — وابستگی‌ها
